# Video to GIF Converter

## 概要

**Video to GIF Converter** は、ブラウザ上（ローカル環境）でmp4やmovなどの動画ファイルを、高画質なGIFまたはWebPアニメーション画像に変換できる強力なツールです。

サーバーへのファイルアップロードが一切不要なため、機密性の高い動画でもプライバシーを気にすることなく安全に利用できます。

## 主な機能

- **ローカル完全完結（セキュア）:** 動画データのアップロードなしにブラウザ上で直接変換処理を行います。
- **ドラッグ＆ドロップ対応:** 簡単な操作で最大2GBまでの動画ファイル（`.mp4`, `.mov`）を読み込めます。
- **Premiereライクな高機能タイムライン:**
  - 再生、停止、コマ送り（左・右）
  - 自由なズームと再生位置（プレイヘッド）のフォーカス
  - 直感的で精密な動画のトリミング機能（イン点・アウト点の設定）
- **柔軟な出力設定:**
  - **フォーマット:** GIF または アニメーションWebP
  - **解像度:** 480px / 600px(推奨) / 720px / 1280px(HD) / 1920px(FHD) / オリジナル
  - **フレームレート(FPS):** 5 / 10 / 15(推奨) / 24 / 30 / オリジナル
- **プレビュー＆ダウンロード:** 生成された画像をその場でプレビュー確認し、すぐにダウンロード可能。

## 使い方

1. **動画を読み込む:**
   画面左側の破線エリアに動画ファイル（mp4等）をドラッグ＆ドロップするか、クリックしてファイルを選択します。
2. **変換範囲をトリミングする（任意）:**
   - プレビュー下部のタイムラインを使って、変換したい範囲を指定します。
   - 再生ヘッド（縦線）を動かし、「[ 開始」ボタン（イン点）と「終了 ]」ボタン（アウト点）で切り抜く範囲を決定します。
   - タイムライン左右の端のハンドルをドラッグして長さを微調整することもできます。
3. **出力設定を調整する:**
   - 画面右側の「設定」パネルから、出力したいフォーマット（GIF / WebP）、解像度、フレームレートを選択します。
   - *※フルHD等の高解像度でのGIF変換はブラウザに多大な負荷がかかるため、高画質を維持したまま変換したい場合は「WebP」形式を強く推奨します。*
4. **変換を実行:**
   - 「変換を実行」ボタンをクリックすると、プログレスバーが表示され変換が開始されます。
5. **保存:**
   - 変換が完了すると、右下にプレビューが表示されます。「ダウンロード」ボタンをクリックして、ファイルを保存してください。

## ライセンスとソースコードの公開

本アプリは、ブラウザでの動画処理を行うためにバックエンドでオープンソースライブラリ `FFmpeg` (FFmpeg.wasm) を使用しています。
FFmpegのライセンス（LGPL/GPL）および周辺ライブラリの利用規定を尊重し、本ツールのソースコード全体をGitHubにてどなたでも閲覧できる状態で公開しています。
